# Visión del producto — Mi Blog

## Visión

Crear un blog personal pequeño, claro y fácil de mantener, donde cualquier visitante pueda descubrir publicaciones y leerlas sin registrarse. El proyecto también debe servir como ejemplo didáctico, mostrando de forma directa cómo Django conecta un modelo, unas vistas y unas plantillas.

## Problema

Compartir textos personales requiere una experiencia completa pero sencilla: encontrar publicaciones, abrir una entrada y volver al listado con facilidad. El proyecto debe ser comprensible para quien está aprendiendo Django y fácil de ejecutar en local.

## Usuarios y necesidades

- **Visitante:** quiere consultar publicaciones, leer una entrada completa y regresar al listado sin iniciar sesión.
- **Autor o administrador:** quiere gestionar las publicaciones mediante el panel estándar de Django.
- **Estudiante o persona que mantiene el proyecto:** quiere comprender rápidamente la estructura y poder ejecutar el blog con los comandos habituales de Django.

## Propuesta de valor

“Mi Blog” ofrece una experiencia de lectura directa y una gestión de contenido sencilla. Su enfoque didáctico y deliberadamente simple permite centrarse en el flujo de publicación y lectura sin añadir complejidad innecesaria.

## Principios del producto

1. **Lectura primero:** priorizar el título, la fecha y el contenido, evitando elementos visuales que distraigan.
2. **Simplicidad didáctica:** seguir la estructura estándar de Django y mantener el código fácil de explicar.
3. **Acceso público, edición protegida:** las publicaciones se leen sin cuenta y se gestionan desde Django Admin.
4. **Experiencia adaptable:** ofrecer una lectura cómoda en móviles y escritorio.
5. **Ejecución local sencilla:** utilizar el flujo habitual de Django y SQLite en desarrollo.
