# Briefing — Blog de tecnología

## Objetivo
Crear un blog personal mínimo, fácil de entender y de mantener, pensado para publicar entradas de texto con título, fecha y contenido.

## Público
Cualquier persona que quiera leer las publicaciones. No requiere cuenta ni login para visitar el blog.

## Alcance (MVP)
Incluye:
- Página de inicio con listado de entradas (título, fecha y extracto)
- Página de detalle de cada entrada
- Navegación básica (inicio ↔ entrada)
- Diseño limpio y legible en móvil y escritorio
- Contenido de ejemplo (2–3 entradas) para probar el flujo

No incluye (fuera de alcance):
- Sistema de usuarios / autenticación
- Comentarios
- Panel de administración complejo
- Buscador, etiquetas o categorías avanzadas
- Newsletter o redes sociales

## Requisitos funcionales
1. Ver el listado de posts en la home.
2. Abrir un post y leer su contenido completo.
3. Volver al listado desde la página del post.
4. Mostrar título, fecha y cuerpo de cada entrada.

## Requisitos no funcionales
- Interfaz clara y tipografía legible
- Carga rápida y sin dependencias innecesarias
- Código simple y bien organizado (fácil de explicar en clase)
- Responsive (móvil y desktop)

## Contenido inicial
- Nombre del blog: a definir (propuesta: “Mi Blog”)
- 2–3 posts de ejemplo con texto ficticio
- Sin imágenes obligatorias en la primera versión

## Criterios de aceptación
- Un visitante puede listar posts y leer uno completo sin fricción
- El proyecto se entiende en pocos minutos (estructura clara)
- Funciona en el navegador sin pasos complicados de despliegue

## Entregables
- Código fuente del blog
- Este briefing actualizado si cambia el alcance
- README breve con cómo abrir/ejecutar el proyecto
